## 🚀 Mise en Ligne Rapide (Hébergement Gratuit)

### Option 1 : Netlify Drop (La plus simple, en 30 secondes)
1. Rendez-vous sur [app.netlify.com/drop](https://app.netlify.com/drop)
2. Glissez-déposez le dossier `AGHAR` dans la zone de dépôt.
3. Votre site est instantanément en ligne avec une adresse HTTPS gratuite et sécurisée (ex: `https://aghar-artisanat.netlify.app`).

### Option 2 : GitHub Pages
1. Créez un nouveau dépôt sur [GitHub](https://github.com/new) nommé `aghar`.
2. Exécutez :
   ```bash
   git remote add origin https://github.com/<votre-nom-d-utilisateur>/aghar.git
   git branch -M main
   git push -u origin main
   ```
3. Dans **Settings > Pages** du dépôt GitHub, sélectionnez la branche `main` et enregistrez.

### Option 3 : Vercel
1. Connectez-vous sur [vercel.com](https://vercel.com).
2. Cliquez sur « Add New Project » et importez le dossier ou le dépôt GitHub.
